## Giới thiệu về Localization {#introduction-to-localization}
Chuyện rất phổ biến là các ứng dụng phần mềm được sử dụng bởi người dùng khắp nơi trên thế giới, những người nói các ngôn ngữ khác nhau và sống ở nhiều quốc gia, nền văn hóa khác nhau. Để một ứng dụng có thể tiếp cận toàn cầu và thân thiện với người dùng, nó cần thích ứng với ngôn ngữ và các chuẩn mực văn hóa của người dùng. Đây chính là lúc localization phát huy vai trò.

Localization là quá trình thiết kế và phát triển ứng dụng của bạn theo cách có thể thích ứng với nhiều locale khác nhau mà không cần thay đổi gì về mặt engineering. Hãy nghĩ về nó như việc tạo ra một ứng dụng "sẵn sàng cho toàn cầu".

Một locale đại diện cho một vùng địa lý, chính trị hoặc văn hóa cụ thể. Nó bao gồm một language code, một country code và tùy chọn, một variant.

Dưới đây là một ví dụ về biểu diễn của một locale:
```
fr_CA
```

Lưu ý rằng:
- Phần language là bắt buộc
- Phần country là tùy chọn (nhưng nếu bạn chọn bao gồm nó, nó phải tuân theo đúng định dạng)
- Phần language viết thường
- Phần country viết hoa
- Language và country được phân tách bằng dấu gạch dưới

Ví dụ, `en` đại diện cho tiếng Anh, `en_US` đại diện cho tiếng Anh được dùng ở Hoa Kỳ, có thể khác với `en_UK` (tiếng Anh dùng ở Vương quốc Anh) ở những điểm như chính tả (color so với colour), từ vựng (truck so với lorry) hoặc đơn vị tiền tệ ($100 so với £100).

## Class `Locale` {#the-locale-class}
Các locale được biểu diễn bởi class `java.util.Locale`. Về cơ bản, class này đại diện cho một ngôn ngữ và một quốc gia, mặc dù chính xác hơn thì một locale có thể chứa các thông tin sau:

- Một language code ISO 639 alpha-2 hoặc alpha-3, ví dụ *ja* (Japanese)
- Một country code ISO 3166 alpha-2 hoặc mã vùng UN M.49 numeric-3, ví dụ *JP* (Japan)
- Một variant name, thường rỗng nhưng có thể là bất kỳ string nào.
- Một script code ISO 15924 alpha-4, ví dụ *Latn* (Latin)
- Một tập các extension được biểu diễn bằng những ký tự đơn, ví dụ *u*.

Có nhiều cách để lấy hoặc tạo một object `Locale` trong Java.

Để lấy locale mặc định của Java Virtual Machine (JVM), bạn dùng:

```java
Locale locale = Locale.getDefault();
```

Class `Locale` cung cấp một số hằng số built-in cho các locale thường dùng. Ví dụ:

```java
Locale usLocale = Locale.US;  // Tiếng Anh như được dùng ở Mỹ
Locale frLocale = Locale.FRANCE; // Tiếng Pháp như được dùng ở Pháp 
```

Bạn cũng có thể tạo một object `Locale` mới bằng một trong các constructor của nó:
```java
Locale(String language)
Locale(String language, String country)
Locale(String language, String country, String variant)
```

Ví dụ:

```java
Locale locale = new Locale("fr", "CA", "POSIX");
```

Đoạn code này tạo một object `Locale` mới đại diện cho tiếng Pháp được dùng ở Canada với variant POSIX.

Tham số đầu tiên là language code, tham số thứ hai là country code, và tham số thứ ba (tùy chọn) là variant code. Language code là mã hai hoặc ba chữ cái viết thường theo định nghĩa của ISO 639. Country code là mã hai chữ cái viết hoa theo định nghĩa của ISO 3166. Variant là một giá trị tùy ý được dùng để chỉ bất kỳ loại biến thể nào, không chỉ các biến thể về ngôn ngữ.

Bạn cũng có thể dùng factory method `forLanguageTag(String)`. Method này nhận một language code, ví dụ:
```java
Locale german = Locale.forLanguageTag("de");
```

Ngoài ra, bằng cách dùng `Locale.Builder`, bạn có thể set các thuộc tính cần thiết rồi build object ở bước cuối, ví dụ:
```java
Locale japan = new Locale.Builder()
                 .setRegion("JP")
                 .setLanguage("ja")
                 .build();
```

Truyền một argument không hợp lệ vào bất kỳ constructor và method nào ở trên sẽ không throw exception, nó chỉ tạo ra một object với các tùy chọn không hợp lệ khiến chương trình của bạn hoạt động sai:
```java
Locale badLocale = new Locale("a", "A"); // Không có error
System.out.println(badLocale); // Nó in ra a_A
```

Method `getDefault()` trả về giá trị hiện tại của locale mặc định cho instance Java Virtual Machine (JVM) này. JVM thiết lập locale mặc định trong lúc khởi động dựa trên môi trường host. Nó được nhiều method nhạy cảm với locale sử dụng nếu không có locale nào được chỉ định tường minh. Tuy nhiên, nó có thể được thay đổi bằng method `setDefault(Locale)`:
```java
System.out.println(Locale.getDefault()); // Giả sử nó in ra en_GB
Locale.setDefault(new Locale("en", "US"));
System.out.println(Locale.getDefault()); // Bây giờ in ra en_US
```

### Các category của Locale {#locale-categories}
Enum `Locale.Category` định nghĩa hai category dùng để phân biệt các mục đích mà một `Locale` có thể được sử dụng: `Locale.Category.DISPLAY` và `Locale.Category.FORMAT`. Các category này giúp chỉ định những thiết lập locale nào sẽ được áp dụng trong các ngữ cảnh khác nhau.

1. **Locale.Category.DISPLAY**:
   - Category này được dùng cho các string của user interface, như message, label và menu.
   - Nó được áp dụng khi bạn cần localize nội dung được hiển thị cho người dùng.
   - Ví dụ, khi một ứng dụng cần hiển thị date, time hoặc currency theo cách đã localize, nó dùng locale `DISPLAY` để đảm bảo các định dạng và message phù hợp với ngôn ngữ và khu vực của người dùng.

2. **Locale.Category.FORMAT**:
   - Category này được dùng để format date, number và các giá trị khác thuộc phần xử lý dữ liệu hoặc hệ thống backend.
   - Nó được áp dụng khi bạn cần parse, format hoặc validate dữ liệu nhạy cảm với locale.
   - Ví dụ, khi bạn cần format một date để lưu trữ hoặc xử lý tiếp, locale `FORMAT` được dùng để đảm bảo dữ liệu tuân theo đúng định dạng đã localize.

Dưới đây là một ví dụ minh họa cách dùng các category này:

```java
// Thiết lập locale DISPLAY
Locale.setDefault(Locale.Category.DISPLAY, Locale.FRANCE);

// Thiết lập locale FORMAT
Locale.setDefault(Locale.Category.FORMAT, Locale.US);

// Lấy locale DISPLAY
Locale displayLocale = Locale.getDefault(Locale.Category.DISPLAY);
System.out.println("DISPLAY Locale: " + displayLocale);

// Lấy locale FORMAT
Locale formatLocale = Locale.getDefault(Locale.Category.FORMAT);
System.out.println("FORMAT Locale: " + formatLocale);
```

Trong ví dụ này, locale `DISPLAY` được set thành `Locale.FRANCE`, nghĩa là các thành phần user interface sẽ được localize cho người dùng Pháp. Locale `FORMAT` được set thành `Locale.US`, nghĩa là mọi định dạng date hoặc number sẽ tuân theo quy ước được dùng ở Hoa Kỳ.

Kết quả là:
```
DISPLAY Locale: fr_FR
FORMAT Locale: en_US
```

Dưới đây là một sơ đồ tóm tắt cấu trúc của một locale:
```
┌──────────────────────────────────────────┐
│              Locale Structure            │
│                                          │
│  ┌───────────────────────────────────┐   │
│  │              Locale               │   │
│  │  ┌─────────────┐ ┌─────────────┐  │   │
│  │  │  Language   │ │  Country    │  │   │
│  │  │   (en)      │ │   (US)      │  │   │
│  │  └─────────────┘ └─────────────┘  │   │
│  │         ┌─────────────┐           │   │
│  │         │  Variant    │           │   │
│  │         │ (Optional)  │           │   │
│  │         └─────────────┘           │   │
│  └───────────────────────────────────┘   │
│                                          │
│  Locale Categories:                      │
│  ┌─────────────┐ ┌─────────────┐         │
│  │ DISPLAY     │ │ FORMAT      │         │
│  │             │ │             │         │
│  └─────────────┘ └─────────────┘         │
│                                          │
│  Examples:                               │
│  - en_US                                 │
│  - fr_FR                                 │
│  - de_DE_EURO                            │
│                                          │
└──────────────────────────────────────────┘

Key Points:
- Language is required, country and variant are optional
- Language codes are lowercase, country codes are uppercase
- Variant is used for further distinction (such as dialect)
- DISPLAY category affects how the locale itself is displayed
- FORMAT category affects formatting of dates, numbers, etc.
```

## Resource Bundle {#resource-bundles}
Resource bundle là một cách để tổ chức và truy cập dữ liệu đặc thù theo locale như message hoặc label trong ứng dụng của bạn. Hãy nghĩ về nó như một collection các cặp key-value, trong đó key giống nhau trên mọi locale nhưng value thì đặc thù cho từng locale.

Để hỗ trợ điều này, chúng ta có một abstract class `java.util.ResourceBundle` với hai subclass:

- `java.util.PropertyResourceBundle`: Mỗi locale được biểu diễn bằng một property file. Key và value có kiểu `String`.

- `java.util.ListResourceBundle`: Mỗi locale được biểu diễn bằng một subclass của class này, override method `Object[][] getContents()`. Array được trả về biểu diễn các key và value. Key phải có kiểu `String`, nhưng value có thể là bất kỳ object nào.

Trong Java, resource bundle thường được triển khai dưới dạng property file. Property file là một file văn bản thuần chứa các cặp key-value phân tách bằng dấu bằng (`=`). Ví dụ:

```
greeting=Hello
farewell=Goodbye
```

Tên của property file rất quan trọng. Nó phải theo định dạng `<basename>_<language>_<country>_<variant>.properties`, trong đó:
- `<basename>` là tên bạn đặt cho resource bundle
- `<language>` là language code ISO-639 hai chữ cái viết thường
- `<country>` là country code ISO-3166 hai chữ cái viết hoa 
- `<variant>` là mã tùy chọn dành riêng cho vendor hoặc browser

Ví dụ, chúng ta có thể có các bundle với những tên sau (giả sử chúng ta đang làm việc với property file, dù với class cũng tương tự):
```
MyBundle.properties
MyBundle_en.properties
MyBundle_en_NZ.properties
MyBundle_en_US.properties
```

Trong trường hợp này, `MyBundle_en_US.properties` sẽ chứa các message cho tiếng Anh được dùng ở Hoa Kỳ.

Để tạo một resource bundle, trước tiên bạn tạo các property file cho từng locale bạn muốn hỗ trợ. Sau đó, bạn dùng class `java.util.ResourceBundle` để load property file phù hợp với locale hiện tại:

```java
ResourceBundle bundle = ResourceBundle.getBundle("MyBundle", locale);
```

Đoạn code này load resource bundle có tên `MyBundle` cho locale được chỉ định. Java sẽ tìm property file khớp nhất với locale được yêu cầu dựa trên thứ tự ưu tiên sau:

1. Language + Country + Variant
2. Language + Country
3. Language
4. Locale mặc định (như được trả về bởi `Locale.getDefault()`)
5. Root resource bundle (chỉ basename, không có thông tin locale)

Nếu không tìm thấy property file khớp, một `MissingResourceException` sẽ được throw.

Khi đã có một `ResourceBundle`, bạn có thể lấy value đặc thù cho locale ứng với một key bằng method `getString`:
```java
String greeting = bundle.getString("greeting");
```

Để lấy một value dạng object, dùng:
```java
Integer num = (Integer) bundle.getObject("number");
```

Điều quan trọng cần lưu ý là `getString(key)` thực chất là cách viết tắt của:
```java
String val = (String) bundle.getObject(key);
```

Bạn có thể dùng các key của resource bundle khớp và bất kỳ parent nào của nó.

Parent của một resource bundle là những bundle có cùng tên nhưng ít thành phần hơn. Ví dụ, parent của `MyBundle_es_ES` là:
```
MyBundle_es
MyBundle
```

Giả sử locale mặc định là `en_US`, và chương trình của bạn đang dùng những property file này cùng các file khác, tất cả đều trong default package, với các giá trị:
```
MyBundle_en.properties
s = buddy

MyBundle_es_ES.properties
s = tío

MyBundle_es.properties
s = amigo

MyBundle.properties
hi = Hola
```

Chúng ta có thể tạo một resource bundle như sau:
```java
Locale spain = new Locale("es", "ES");
Locale spanish = new Locale("es");

ResourceBundle rb = ResourceBundle.getBundle("MyBundle", spain);
System.out.format("%s %s\n",
    rb.getString("hi"), rb.getString("s"));

rb = ResourceBundle.getBundle("MyBundle", spanish);
System.out.format("%s %s\n",
    rb.getString("hi"), rb.getString("s"));
```

Kết quả sẽ là:
```
Hola tío
Hola amigo
```

Như bạn thấy, mỗi locale chọn value khác nhau cho key `s`, nhưng cả hai đều dùng cùng một value cho `hi` vì key này được định nghĩa trong parent của chúng.

Nếu bạn không chỉ định locale, class `ResourceBundle` sẽ dùng locale mặc định của hệ thống:
```java
ResourceBundle rb = ResourceBundle.getBundle("MyBundle");
System.out.format("%s %s\n",
    rb.getString("hi"), rb.getString("s"));
```

Vì chúng ta giả sử locale mặc định là `en_US`, kết quả là:
```
Hola buddy
```

Chúng ta cũng có thể lấy tất cả key trong một resource bundle bằng method `keySet()`:
```java
ResourceBundle rb =
    ResourceBundle.getBundle("MyBundle", spain);
Set<String> keys = rb.keySet();
keys.stream()
    .forEach(key ->
        System.out.format("%s %s\n", key, rb.getString(key)));
```

Kết quả là (lưu ý nó cũng in ra key của parent):
```
hi Hola
s tío
```


## Class `MessageFormat` {#the-messageformat-class}
Đôi khi, bạn cần format các message có chứa dữ liệu thay đổi. Ví dụ, bạn có thể muốn hiển thị một lời chào được cá nhân hóa kèm tên người dùng, hoặc một error message chứa thông tin chi tiết cụ thể về error đó. 

Class `java.text.MessageFormat` cung cấp một cách mạnh mẽ để tạo các message đã localize bằng cách kết hợp một pattern string với các argument. Nó cho phép bạn định nghĩa một message template với các placeholder cho dữ liệu thay đổi, rồi thay thế những placeholder đó bằng giá trị thực tế tại runtime.

Method quan trọng trong class `MessageFormat` là `format`:
```java
static String format(String pattern, Object... arguments)
```

Static method này nhận một message pattern và một array các argument, rồi trả về message đã format dưới dạng string. Tuy nhiên, có hai method `format` khác được định nghĩa là instance method:
```java
final StringBuffer format(Object[] arguments, StringBuffer result, FieldPosition pos)
final StringBuffer format(Object arguments, StringBuffer result, FieldPosition pos)
```

Các method này format một array các object và nối pattern của instance `MessageFormat`, với các format element được thay bằng những object đã format, vào `StringBuffer` được cung cấp.

Ngoài ra, parent class của nó, `java.text.Format`, định nghĩa thêm một method `format` khác:
```java
public final String format(Object obj)
```

Method này format một object để tạo ra một string. Nó tương đương với:
```java
format(obj, new StringBuffer(), new FieldPosition(0)).toString();
```

Message pattern là một string bao gồm phần text tĩnh của message, cùng các placeholder cho những phần thay đổi. Các placeholder được đánh dấu bằng dấu ngoặc nhọn `{}` và một con số chỉ vị trí của argument trong argument array.

Cú pháp của một message format pattern tuân theo cấu trúc sau:

```
Literal text {argumentIndex,formatType,formatStyle} Literal text
```

Trong đó:

- **Literal Text**: Đây là bất kỳ text nào bạn muốn đưa trực tiếp vào message. Ví dụ, trong `Hello, {0}`, `Hello, ` là literal text.

- **Argument Index**: `{argumentIndex}` chỉ định vị trí chèn một argument. Con số bên trong dấu ngoặc nhọn tương ứng với vị trí của argument trong danh sách bạn cung cấp khi format message. Ví dụ, `{0}` sẽ được thay bằng argument đầu tiên, `{1}` bằng argument thứ hai, v.v.

-. **Format Type**: `{argumentIndex,formatType}` thêm một format type cho argument. Các format type phổ biến gồm:
   - `number`: Format argument dưới dạng number.
   - `date`: Format argument dưới dạng date.
   - `time`: Format argument dưới dạng time.
   - `choice`: Dùng choice format cho argument.

- **Format Style**: `{argumentIndex,formatType,formatStyle}` tinh chỉnh thêm format type với một style cụ thể. Ví dụ:
   - `number,currency`: Format number dưới dạng currency.
   - `date,short`: Format date theo style short.
   - `number,percent`: Format number dưới dạng percentage.

Text có thể được quote bằng dấu nháy đơn `'`, và dấu này được escape thành `''`. Mọi dấu ngoặc nhọn không khớp cặp phải được escape bằng một dấu nháy đơn. Ví dụ:
- `"'{0}'"` biểu diễn literal string `"{0}"` 
- `"'{'"` biểu diễn literal string `"{"` 
- `"'}'"` biểu diễn literal string `"}"` 

Dưới đây là một số ví dụ về các message format pattern hợp lệ:

- **Simple Argument Insertion**:
  ```
  "The value is {0}"
  ```
  Nếu argument là `42`, kết quả sẽ là "The value is 42".

- **Number Formatting**:
  ```
  "The total amount is {0,number,currency}"
  ```
  Nếu argument là `1234.56`, kết quả sẽ là "The total amount is $1,234.56".

- **Date Formatting**:
  ```
  "The date today is {0,date,full}"
  ```
  Nếu argument là một date, kết quả có thể là "The date today is Thursday, July 25, 2024".

- **Choice Formatting**:
  ```
  "There are {0,choice,0#no files|1#one file|1<many files}"
  ```
  Nếu argument là `0`, `1` hoặc `2`, kết quả lần lượt sẽ là `There are no files`, `There is one file` hoặc `There are many files`.


Tuy nhiên, thay vì dùng static method `format`, bạn có thể tạo một instance `MessageFormat` bằng cách truyền một pattern string vào constructor của class và tùy chọn truyền một `Locale` vào constructor:

```java
String pattern = "The disk \"{1}\" contains {0} file(s).";
MessageFormat messageFormat = new MessageFormat(pattern, Locale.US);
```

Bạn cũng có thể set `Locale` cho instance `MessageFormat` bằng `setLocale()`. Điều này quyết định cách các argument được format.

Dù thế nào, để tạo một message string đã format, hãy gọi `format()` với một array các argument object:

```java
Object[] arguments = {42, "MyDisk"};
String result = messageFormat.format(arguments);
// kết quả: "The disk "MyDisk" contains 42 file(s)."
```

Có một số quy tắc về argument index:
- `format()` thay mỗi format element `{argumentIndex}` bằng object tương ứng từ array `arguments`.  
- Nếu một argument index được dùng nhiều lần, mọi lần xuất hiện đều được thay bằng cùng một value đã format.
- Các argument không dùng đến sẽ bị bỏ qua. Argument thiếu hoặc thừa sẽ gây ra exception.

Giả sử chúng ta có message format pattern và các argument sau:

```java
String pattern = "Hello, {0}. Today is {1,date,long}. Your balance is {2,number,currency}. Hello again, {0}!";
Object[] arguments = {"John", new Date(), 1234.56};
```

Khi chúng ta format pattern này với array `arguments`, đây là cách nó hoạt động:

- `{0}` được thay bằng `John`.
- `{1,date,long}` được thay bằng date hiện tại theo long format (ví dụ, `July 25, 2024`).
- `{2,number,currency}` được thay bằng number đã format theo currency (ví dụ, `$1,234.56`).
- Lần xuất hiện thứ hai của `{0}` cũng được thay bằng `John`.

Đây là message đã format thu được:

```
"Hello, John. Today is July 25, 2024. Your balance is $1,234.56. Hello again, John!"
```

Về các format type và style:
- Nếu không chỉ định format type, một giá trị mặc định dựa trên kiểu của argument sẽ được dùng (ví dụ, number dùng `NumberFormat`).
- Có thể định nghĩa format type tùy chỉnh bằng cách truyền một subformat pattern string, ví dụ `{0,number,#,##0.0}`.
- `formatStyle` là tùy chọn và có thể chỉ định một style định sẵn như `short`, `long`, `integer`, `currency`, v.v.

Xét message format pattern và các argument sau:

```java
String pattern = "The item costs {0}. The item costs {0,number,currency}. Custom format: {0,number,#,##0.0}. Today is {1,date,long}. Short date: {1,date,short}";
Object[] arguments = {1234.567, new Date()};
```

Khi được format với array `arguments`, nó hoạt động như sau:

- `{0}` không có format type sẽ mặc định theo number format (ví dụ, `1234.567`).
- `{0,number,currency}` chỉ định format type `number` với style `currency` (ví dụ, `$1,234.57`).
- `{0,number,#,##0.0}` dùng một custom number format pattern (ví dụ, `1,234.6`).
- `{1,date,long}` chỉ định format type `date` với style `long` (ví dụ, `July 25, 2024`).
- `{1,date,short}` chỉ định format type `date` với style `short` (ví dụ, `7/25/24`).

Đây là message đã format thu được:

```
"The item costs 1234.567. The item costs $1,234.57. Custom format: 1,234.6. Today is July 25, 2024. Short date: 7/25/24"
```

Ngoài `MessageFormat`, còn có hai subclass khác của `Format`: `java.text.NumberFormat` và `java.text.DateFormat`, lần lượt dùng để format number và date.

Các giá trị format type và style được dùng để tạo một instance `Format` cho format element. Bảng sau cho thấy các giá trị ánh xạ tới các instance `Format` như thế nào. Những tổ hợp không có trong bảng là không hợp lệ. Một *SubformatPattern* phải là một pattern string hợp lệ cho subclass `Format` được dùng.

| FormatType | FormatStyle | Subformat được tạo |
|------------|-------------|-------------------|
| *(không có)*   | *(không có)*    | `null`            |
| `number`   | *(không có)*    | `NumberFormat.getInstance(getLocale())` |
|            | `integer`   | `NumberFormat.getIntegerInstance(getLocale())` |
|            | `currency`  | `NumberFormat.getCurrencyInstance(getLocale())` |
|            | `percent`   | `NumberFormat.getPercentInstance(getLocale())` |
|            | *SubformatPattern* | `new` `DecimalFormat(subformatPattern, DecimalFormatSymbols.getInstance(getLocale()))` |
| `date`     | *(không có)*    | `DateFormat.getDateInstance(DateFormat.DEFAULT, getLocale())` |
|            | `short`     | `DateFormat.getDateInstance(DateFormat.SHORT, getLocale())` |
|            | `medium`    | `DateFormat.getDateInstance(DateFormat.DEFAULT, getLocale())` |
|            | `long`      | `DateFormat.getDateInstance(DateFormat.LONG, getLocale())` |
|            | `full`      | `DateFormat.getDateInstance(DateFormat.FULL, getLocale())` |
|            | *SubformatPattern* | `new` `SimpleDateFormat(subformatPattern, getLocale())` |
| `time`     | *(không có)*    | `DateFormat.getTimeInstance(DateFormat.DEFAULT, getLocale())` |
|            | `short`     | `DateFormat.getTimeInstance(DateFormat.SHORT, getLocale())` |

Trong các phần tiếp theo, chúng ta sẽ xem xét chi tiết hơn các class `NumberFormat` và `DateFormat`.


## Class `NumberFormat` {#the-numberformat-class}
`NumberFormat` là abstract base class dùng để format và parse number trong Java. Nó cung cấp cách xử lý các giá trị số theo hướng nhạy cảm với locale, cho phép bạn format và parse number, currency và percentage theo quy ước của các locale khác nhau.

Để lấy một instance `NumberFormat` cho một locale cụ thể, bạn thường dùng một trong các factory method của nó:

```java
NumberFormat defaultFormat = NumberFormat.getInstance();
NumberFormat currencyFormat = NumberFormat.getCurrencyInstance();
NumberFormat percentFormat = NumberFormat.getPercentInstance();
```

Các method này trả về một formatter đặc thù cho locale dựa trên locale `FORMAT` mặc định. Bạn cũng có thể chỉ định locale một cách tường minh:

```java
Locale franceLocale = new Locale("fr", "FR");
NumberFormat franceFormat = NumberFormat.getInstance(franceLocale);
```

Để format một number, dùng một trong các method `format()`:

```java
double value = 1234.56;
String formattedValue = defaultFormat.format(value);  // "1,234.56"
```

`NumberFormat` cũng cung cấp các method để format giá trị `long` và `double` trực tiếp vào một `StringBuffer`, cách này có thể hiệu quả hơn với những tác vụ format nặng:
```
abstract StringBuffer format(double number, StringBuffer toAppendTo, FieldPosition pos)
abstract StringBuffer format(long number, StringBuffer toAppendTo, FieldPosition pos)
```

Mặt khác, để parse một string thành number, dùng method `parse()`:

```java
String text = "1,234.56";
Number number = defaultFormat.parse(text);  // Trả về một Long hoặc Double
```

Method `parse()` nhạy cảm với locale và sẽ nhận diện các dấu phân cách thập phân và nhóm đặc thù cho locale.

`NumberFormat` cũng cung cấp một số method để kiểm soát output khi format:

- `setMinimumIntegerDigits()` và `setMaximumIntegerDigits()`: Kiểm soát số chữ số trong phần nguyên.
- `setMinimumFractionDigits()` và `setMaximumFractionDigits()`: Kiểm soát số chữ số trong phần thập phân.
- `setGroupingUsed()`: Bật hoặc tắt dấu phân cách nhóm.
- `setRoundingMode()`: Set rounding mode cho formatter.

Để kiểm soát chi tiết hơn, `NumberFormat` có một số subclass cụ thể cho những nhu cầu format đặc thù:

- `DecimalFormat`: Formatter đa dụng cho số thập phân.
- `CompactNumberFormat`: Format number theo cách thu gọn, nhạy cảm với locale, ví dụ "1.2K" cho 1200.
- `ChoiceFormat`: Cho phép bạn ánh xạ number sang string dựa trên một tập các khoảng.

### Class `DecimalFormat` {#the-decimalformat-class}

Subclass được dùng phổ biến nhất là `DecimalFormat`, cho phép kiểm soát ở mức cao đối với formatting pattern. Bạn có thể tạo một `DecimalFormat` với pattern và symbols cụ thể:

```java
DecimalFormat format = new DecimalFormat("#,##0.00", DecimalFormatSymbols.getInstance(Locale.US));
```

Tham số thứ hai (`DecimalFormatSymbols`) là tùy chọn. Pattern chỉ định định dạng của output, với các ký tự đặc biệt đại diện cho vị trí chữ số, phần thập phân, nhóm, v.v. Object `DecimalFormatSymbols` định nghĩa những ký tự cụ thể được dùng cho các ký tự đặc biệt này dựa trên một locale.

Một pattern của `DecimalFormat` chứa một positive và một negative subpattern, ví dụ `#,##0.00;(#,##0.00)`. Mỗi subpattern có một prefix, phần numeric và một suffix. Negative subpattern là tùy chọn; nếu không có, thì positive subpattern được thêm dấu trừ (`'-' U+002D HYPHEN-MINUS`) ở đầu sẽ được dùng làm negative subpattern. 

Nhiều ký tự trong pattern được hiểu theo nghĩa nguyên văn, chúng được so khớp trong lúc parse và giữ nguyên trong output khi format. Ngược lại, các ký tự đặc biệt đại diện cho những ký tự, string hoặc nhóm ký tự khác và chúng phải được quote.

Các ký tự được liệt kê trong bảng sau được dùng trong các pattern chưa localize. Các pattern đã localize dùng những ký tự tương ứng lấy từ object `DecimalFormatSymbols` của formatter này thay thế, và các ký tự đó mất đi trạng thái đặc biệt. Hai ngoại lệ là dấu currency và dấu quote, chúng không được localize:

| Ký hiệu              | Vị trí          | Có localize? | Ý nghĩa                                                                                      |
|----------------------|-----------------|------------|-----------------------------------------------------------------------------------------------|
| `0`                  | Number          | Có         | Chữ số                                                                                       |
| `#`                  | Number          | Có         | Chữ số, số 0 hiển thị dưới dạng không có                                                     |
| `.`                  | Number          | Có         | Dấu phân cách thập phân hoặc dấu phân cách thập phân tiền tệ                                 |
| `-`                  | Number          | Có         | Dấu trừ                                                                                      |
| `,`                  | Number          | Có         | Dấu phân cách nhóm hoặc dấu phân cách nhóm tiền tệ                                           |
| `E`                  | Number          | Có         | Phân tách mantissa và exponent trong ký hiệu khoa học. *Không cần quote trong prefix hoặc suffix.* |
| `;`                  | Ranh giới subpattern | Có    | Phân tách positive và negative subpattern                                                    |
| `%`                  | Prefix hoặc suffix | Có       | Nhân với 100 và hiển thị dưới dạng phần trăm                                                 |
| `&#92;u2030`         | Prefix hoặc suffix | Có       | Nhân với 1000 và hiển thị dưới dạng giá trị per mille                                        |
| `&#164;` (`&#92;u00A4`) | Prefix hoặc suffix | Không    | Dấu currency, được thay bằng ký hiệu tiền tệ. Nếu nhân đôi, được thay bằng ký hiệu tiền tệ quốc tế. Nếu có mặt trong pattern, dấu phân cách thập phân và nhóm tiền tệ được dùng thay cho dấu phân cách thập phân và nhóm. |
| `'`                  | Prefix hoặc suffix | Không      | Dùng để quote các ký tự đặc biệt trong prefix hoặc suffix, ví dụ `" '#' "` format 123 thành `"#123"`. Để tạo chính một dấu nháy đơn, hãy dùng hai dấu liên tiếp: `"# o''clock"`. |


Dưới đây là một số ví dụ:

```java
// Định dạng số
DecimalFormat numberFormat = new DecimalFormat("###,###.##");
System.out.println("Number Formatting: " + numberFormat.format(1234567.89));

// Định dạng phần trăm
DecimalFormat percentFormat = new DecimalFormat("##.##%");
System.out.println("Percentage Formatting: " + percentFormat.format(0.1234));

// Định dạng per mille
DecimalFormat perMilleFormat = new DecimalFormat("##.##‰");
System.out.println("Per Mille Formatting: " + perMilleFormat.format(0.1234));

// Định dạng tiền tệ
DecimalFormat currencyFormat = new DecimalFormat("$###,###.##");
System.out.println("Currency Formatting: " + currencyFormat.format(1234.56));

// Ký pháp khoa học
DecimalFormat scientificFormat = new DecimalFormat("0.###E0");
System.out.println("Scientific Notation: " + scientificFormat.format(12345));

// Subpattern dương và âm
DecimalFormat positiveNegativeFormat = new DecimalFormat("###.##;(#.##)");
System.out.println("Positive Number: " + positiveNegativeFormat.format(1234.56));
System.out.println("Negative Number: " + positiveNegativeFormat.format(-1234.56));

// Text tùy chỉnh với các số
DecimalFormat customTextFormat = new DecimalFormat("'Number: '###");
System.out.println("Custom Text with Numbers: " + customTextFormat.format(123));

// Grouping và dấu phân cách thập phân tùy chỉnh
DecimalFormat customGroupingFormat = new DecimalFormat("'Amount: '###,###.##");
System.out.println("Custom Grouping and Decimal Separators: " + customGroupingFormat.format(1234567.89));

//  Quote các ký tự đặc biệt
DecimalFormat quotingSpecialFormat = new DecimalFormat("''#''###");
System.out.println("Quoting Special Characters: " + quotingSpecialFormat.format(123));

// Định dạng số nguyên
DecimalFormat integerFormat = new DecimalFormat("###");
System.out.println("Integer Formatting: " + integerFormat.format(1234.56));
```

Kết quả là:
```
Number Formatting: 1,234,567.89
Percentage Formatting: 12.34%
Per Mille Formatting: 123.4‰
Currency Formatting: $1,234.56
Scientific Notation: 1.234E4
Positive Number: 1234.56
Negative Number: (1234.56)
Custom Text with Numbers: Number: 123
Custom Grouping and Decimal Separators: Amount: 1,234,567.89
Quoting Special Characters: '123'
Integer Formatting: 1235
```

### Class `CompactNumberFormat` {#the-compactnumberformat-class}
`CompactNumberFormat` hỗ trợ compact number formatting. Định dạng này đặc biệt hữu ích để hiển thị các số lớn theo cách dễ đọc hơn và nhạy cảm với locale.

Class này hỗ trợ hai style:

1. `NumberFormat.Style.SHORT`: Dùng các từ viết tắt (ví dụ, `K` cho thousand, `M` cho million, `B` cho billion, v.v.)
2. `NumberFormat.Style.LONG`: Dùng từ đầy đủ (ví dụ, "thousand", "million")

Để lấy một instance `CompactNumberFormat`, bạn dùng factory method `getCompactNumberInstance()`:

```java
NumberFormat shortFormat = NumberFormat.getCompactNumberInstance(Locale.US, NumberFormat.Style.SHORT);
NumberFormat longFormat = NumberFormat.getCompactNumberInstance(Locale.US, NumberFormat.Style.LONG);
```

Dưới đây là một số ví dụ về cách `CompactNumberFormat` hoạt động:

```java
double number = 1_234_567.89;

System.out.println(shortFormat.format(number));  // Kết quả: 1M
System.out.println(longFormat.format(number));   // Kết quả: 1 million

number = 1_234;
System.out.println(shortFormat.format(number));  // Kết quả: 1K
System.out.println(longFormat.format(number));   // Kết quả: 1 thousand
```

`CompactNumberFormat` tự động điều chỉnh số chữ số hiển thị dựa trên độ lớn của number. Nó cũng xử lý các locale khác nhau một cách phù hợp:

```java
NumberFormat frFormat = NumberFormat.getCompactNumberInstance(Locale.FRANCE, NumberFormat.Style.SHORT);
System.out.println(frFormat.format(1_234_567.89));  // Kết quả: 1 M
```

Mặc định, `CompactNumberFormat` không hiển thị phần thập phân. Tuy nhiên, bạn có thể thay đổi hành vi này bằng các method `setMinimumFractionDigits()` và `setMaximumFractionDigits()`. 

Ngoài ra, class này cũng hỗ trợ nhiều rounding mode khác nhau bằng cách dùng `setRoundingMode` và enum `java.math.RoundingMode`, với mặc định là `RoundingMode.HALF_EVEN`:

| Enum Constant | Mô tả |
|---------------|-------------|
| `CEILING` | Rounding mode làm tròn về phía dương vô cực. |
| `DOWN` | Rounding mode làm tròn về phía số 0. |
| `FLOOR` | Rounding mode làm tròn về phía âm vô cực. |
| `HALF_DOWN` | Rounding mode làm tròn về "hàng xóm gần nhất" trừ khi cả hai hàng xóm cách đều, khi đó làm tròn xuống. |
| `HALF_EVEN` | Rounding mode làm tròn về "hàng xóm gần nhất" trừ khi cả hai hàng xóm cách đều, khi đó làm tròn về hàng xóm chẵn. |
| `HALF_UP` | Rounding mode làm tròn về "hàng xóm gần nhất" trừ khi cả hai hàng xóm cách đều, khi đó làm tròn lên. |
| `UNNECESSARY` | Rounding mode khẳng định rằng phép toán được yêu cầu có kết quả chính xác, do đó không cần làm tròn. |
| `UP` | Rounding mode làm tròn ra xa số 0. |

Dưới đây là một số ví dụ:

```java
double number = 1_234_567.89;
NumberFormat shortFormat = NumberFormat.getCompactNumberInstance(Locale.US, NumberFormat.Style.SHORT);

// Hành vi mặc định (không có chữ số thập phân)
System.out.println(shortFormat.format(number));  // Kết quả: 1M

// Thêm các chữ số thập phân
shortFormat.setMinimumFractionDigits(1);
shortFormat.setMaximumFractionDigits(2);
System.out.println(shortFormat.format(number));  // Kết quả: 1.23M

// Thay đổi rounding mode
shortFormat.setRoundingMode(RoundingMode.DOWN);
System.out.println(shortFormat.format(number));  // Kết quả: 1.23M

shortFormat.setRoundingMode(RoundingMode.UP);
System.out.println(shortFormat.format(number));  // Kết quả: 1.24M

// Hành vi với các số nhỏ hơn
number = 1234.56;
System.out.println(shortFormat.format(number));  // Kết quả: 1.24K

// Đặt lại về hành vi mặc định
shortFormat = NumberFormat.getCompactNumberInstance(Locale.US, NumberFormat.Style.SHORT);
System.out.println(shortFormat.format(number));  // Kết quả: 1K
```


## Class `DateTimeFormatter` {#the-datetimeformatter-class}
Trong chương [Date API](ch11.html#parsing-and-formatting), chúng ta đã tìm hiểu class `java.time.format.DateTimeFormatter`, cung cấp một cách linh hoạt và hiện đại để format date và time được biểu diễn bởi các class `java.time` như `LocalDate`, `LocalTime` và `LocalDateTime`.

Tuy nhiên, một trong những tính năng chính của `DateTimeFormatter` là khả năng tạo các formatter đã localize bằng các method `ofLocalized...()`:

- `static DateTimeFormatter ofLocalizedDate(FormatStyle dateStyle)`: Tạo một formatter format date theo style được chỉ định cho locale hiện tại.
- `static DateTimeFormatter ofLocalizedTime(FormatStyle timeStyle)`: Tạo một formatter format time theo style được chỉ định cho locale hiện tại.
- `static DateTimeFormatter ofLocalizedDateTime(FormatStyle dateStyle, FormatStyle timeStyle)`: Tạo một formatter format date và time theo các style được chỉ định cho locale hiện tại.
- `static DateTimeFormatter ofLocalizedDateTime(FormatStyle dateTimeStyle)`: Tạo một formatter format date và time theo style kết hợp được chỉ định cho locale hiện tại.

Enum `FormatStyle` định nghĩa các style có sẵn: `SHORT`, `MEDIUM`, `LONG` và `FULL`.

Dưới đây là một ví dụ về cách dùng các method này:

```java
LocalDate date = LocalDate.now();
LocalTime time = LocalTime.now();
LocalDateTime dateTime = LocalDateTime.now();

DateTimeFormatter dateFormatter = DateTimeFormatter.ofLocalizedDate(FormatStyle.FULL);
DateTimeFormatter timeFormatter = DateTimeFormatter.ofLocalizedTime(FormatStyle.MEDIUM);
DateTimeFormatter dateTimeFormatter = DateTimeFormatter.ofLocalizedDateTime(FormatStyle.LONG, FormatStyle.SHORT);

String formattedDate = date.format(dateFormatter);
String formattedTime = time.format(timeFormatter);
String formattedDateTime = dateTime.format(dateTimeFormatter);

System.out.println("Formatted date: " + formattedDate);
System.out.println("Formatted time: " + formattedTime);
System.out.println("Formatted date-time: " + formattedDateTime);
```

Các method `ofLocalized...()` tự động dùng locale hiện tại để xác định định dạng phù hợp. Nếu bạn muốn chỉ định một locale khác, bạn có thể dùng method `withLocale()`:

```java
DateTimeFormatter frenchDateFormatter = DateTimeFormatter.ofLocalizedDate(FormatStyle.FULL).withLocale(Locale.FRANCE);
String formattedDateInFrench = date.format(frenchDateFormatter);
System.out.println("Formatted date in French: " + formattedDateInFrench);
```

Các localized formatter này mang lại cách dễ dàng để format date và time theo quy ước của một locale cụ thể mà không cần chỉ định format pattern thủ công.

Bạn cũng có thể dùng một pattern để tạo instance `DateTimeFormatter` bằng các method `ofPattern(String)` và `ofPattern(String, Locale)`. Ví dụ, `"d MMM uuuu"` sẽ format `2011-12-03` thành `'3 Dec 2011'`. Một formatter được tạo từ pattern có thể được dùng bao nhiêu lần tùy ý. Nó immutable và thread-safe.

Dưới đây là một ví dụ:

```java
LocalDate date = LocalDate.now();
```

## Các điểm chính {#key-points}

- Localization là quá trình thiết kế và phát triển một application sao cho nó có thể được thích ứng với nhiều locale khác nhau mà không cần thay đổi về mặt engineering. Một locale đại diện cho một vùng địa lý, chính trị hoặc văn hóa cụ thể.

- Locale được đại diện bởi class `java.util.Locale`. Bạn có thể lấy default locale của Java Virtual Machine bằng `Locale.getDefault()`, dùng các constant built-in như `Locale.US`, hoặc tạo một object `Locale` mới bằng constructor hoặc method `forLanguageTag()`.

- Enum `Locale.Category` định nghĩa hai category: `DISPLAY` (cho các thành phần user interface) và `FORMAT` (cho việc parse và format dữ liệu). Bạn có thể set và get default locale cho từng category bằng `Locale.setDefault()` và `Locale.getDefault()`.

- Resource bundle được dùng để tổ chức và truy cập dữ liệu theo từng locale. Chúng thường được implement dưới dạng property file được đặt tên theo format `<basename>_<language>_<country>_<variant>.properties`.

- Class `java.util.ResourceBundle` được dùng để load property file phù hợp cho locale hiện tại. Bạn có thể lấy các giá trị theo từng locale bằng `getString()` hoặc `getObject()`.

- Class `java.text.MessageFormat` được dùng để tạo các message đã localized bằng cách kết hợp một pattern string với các argument. Pattern bao gồm các placeholder được đánh dấu bằng `{}` và argument index. Có thể chỉ định format type (như `number` hoặc `date`) và style.

- Class `java.text.Format` có các subclass để format argument dựa trên kiểu của chúng và format style được chỉ định. Các subclass chính là `java.text.NumberFormat` cho number và `java.text.DateFormat` cho date.

- `java.text.NumberFormat` là abstract base class để format và parse number trong Java. Nó cung cấp các factory method để lấy formatter theo locale cho number, currency và percentage.

- `java.text.DecimalFormat` là concrete subclass của `NumberFormat`, cho phép kiểm soát chi tiết hơn việc format số thập phân bằng pattern. Pattern có thể chứa các ký tự đặc biệt đại diện cho vị trí chữ số, dấu thập phân, grouping, v.v.

- `java.time.format.DateTimeFormatter` là class dùng để format date và time từ package `java.time`. Nó hoạt động với các class date/time hiện đại như `LocalDate`, `LocalTime`, `LocalDateTime`.

- `DateTimeFormatter` cung cấp các method `ofLocalized...()` để tạo formatter theo từng locale với nhiều style khác nhau, tương tự `DateFormat`. Nó cũng cho phép tạo formatter từ custom pattern bằng `ofPattern()`.

- Với certification exam, hãy tập trung vào các pattern phổ biến như era (`G`), year of era (`y`), month (`M`), day of month (`d`), hours (`H`, `h`), minutes (`m`), seconds (`s`), AM/PM (`a`), cùng nhiều pattern khác.
